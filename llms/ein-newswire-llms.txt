# EIN Presswire (EIN Newswire)

> EIN Presswire is a press release distribution service operated by Newsmatics Inc.
> (Washington, D.C.), trading as EIN Presswire. It distributes press releases to media
> outlets, journalists, search engines, news aggregators and the public, syndicating to
> AP News, the USA TODAY Network, Nexstar Media Group, Google News, Bloomberg Terminals,
> MuckRack, Moody's NewsEdge and Naviga, and publishes the results as RSS feeds.

Generated by API Evangelist (https://apievangelist.com) on 2026-09-06 from the public

## Important: there is no API

EIN Presswire publishes no public API, no OpenAPI/AsyncAPI/GraphQL contract, no SDK and
no developer portal. The FAQ states that all press releases must be submitted through
the website submission form and that submissions are only accepted through the website.
Do not attempt programmatic submission; there is no documented endpoint to call.

The only machine-readable surface EIN Presswire publishes is RSS. The parent company,
Newsmatics Inc., separately sells a News Index API on newsmatics.com — that is a
different product and is not an EIN Presswire interface.

## Machine-readable content feeds

- [RSS Feeds](https://www.einpresswire.com/all-rss): full catalog of newswire feeds by
  industry, country and US state. Per-account release feeds are available from the
  My Press Releases page for signed-in users.
- [Publisher Affiliate Program](https://www.einpresswire.com/publisher-affiliate-program):
  publishers receive a custom full-text RSS feed for republication. The feed shape is not
  publicly documented; affiliates@einpresswire.com issues the specification.
